# Beginner Level (Weeks 1-4)

Start here! These are the foundations. Master these before moving to intermediate.

## Topics

### 1. Arrays (Week 1)
- Most common data structure in interviews
- Learn: indexing, slicing, two pointers, sliding window
- **Start here first!**

### 2. Strings (Week 2)
- Very similar to arrays
- Learn: string manipulation, pattern matching
- Uses same techniques as arrays

### 3. Basic Math (Week 3)
- Number operations, prime numbers, GCD/LCM
- Important for problem-solving logic

### 4. Two Pointers (Week 3-4)
- Critical optimization technique
- Reduces O(n²) to O(n) for many problems

## Tips for Beginners

1. **Don't rush** - Understanding > Speed
2. **Code it yourself** - No copy-paste from solutions
3. **Struggle first** - Try for 30-45 min before looking at hints
4. **Review weekly** - Revisit problems after 3 days, 1 week
5. **Ask "why"** - Understand the pattern, not just the solution

You got this! 🚀
