# Week 1: Arrays

**Goal**: Master array operations and solve your first 5 LeetCode problems!

## Learning Path

### Step 1: Learn Theory (30 minutes)
- Read `theory.md` completely
- Understand time/space complexity
- Try examples in Python REPL

### Step 2: Implement from Scratch (1-2 hours)
- Open `implementation.py`
- Implement each function yourself
- Run tests to verify

### Step 3: Solve LeetCode Problems (Daily)

**Problems to solve this week:**

1. ✅ **Two Sum (LC 1)** - Easy
   File: `problems/01_two_sum.py`
   Pattern: Hash Map
   Time: 30-45 min

2. ✅ **Best Time to Buy/Sell Stock (LC 121)** - Easy
   File: `problems/02_best_time_to_buy_sell_stock.py`
   Pattern: Single Pass
   Time: 30-45 min

3. ✅ **Contains Duplicate (LC 217)** - Easy
   File: `problems/03_contains_duplicate.py`

   File: `problems/04_product_except_self.py`

## How to Approach Each Problem

1. **Read problem carefully** (2-3 times)
2. **Write down examples** (including edge cases)
3. **Think of brute force first** (it's okay if it's slow!)
4. **Code brute force**
5. **Think optimization** (can hash map help? two pointers?)
6. **Code optimal solution**
7. **Test with edge cases**
8. **Review solution discussion** (learn alternative approaches)
