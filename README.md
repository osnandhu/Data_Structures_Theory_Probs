```

```

```

```
Rest OR review toughest problems from week

## 🆘 When You're Stuck (Critical!)

Read `PROBLEM_SOLVING_GUIDE.md` for detailed strategies.

**Quick version:**
1. **0-30 min**: Try yourself (brute force is okay!)
2. **30-45 min**: Look at hints only (not solution)
3. **45-60 min**: Watch explanation video (NeetCode, YouTube)
4. **After 60 min**: Read solution, understand WHY, code yourself
5. **Mark for review**: Revisit in 3 days, 1 week

**Getting stuck is normal. Getting unstuck is the skill.**

## ❓ FAQ

### "Can I really become a software engineer if I'm not good at problem-solving?"
Yes. Problem-solving is a skill, not a talent. You build it through practice.

### "How long will this take?"
- **Minimum**: 12 weeks (2-3 hours/day, 5-6 days/week)
- **Realistic**: 16 weeks (accounts for harder topics, life)
- **Timeline**: Doesn't matter. Progress matters.

### "What if I can't solve a problem?"
That's normal! Use the PROBLEM_SOLVING_GUIDE.md. Learning from solutions is part of the process.

### "Should I memorize solutions?"
NO. Understand patterns. If you can explain WHY a solution works, you've learned it.

### "Do I need to solve 1000 problems?"
No. 100-150 problems solved deeply > 500 problems seen once.

### "When am I ready for interviews?"
When you can:
- Solve 70%+ of LC Easy without hints
- Solve 40%+ of LC Medium (hints okay)
- Explain your solutions clearly
- Complete mock interviews confidently
