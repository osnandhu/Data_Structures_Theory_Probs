# Intermediate Level (Weeks 4-8)

**Prerequisites**: Complete all Beginner topics first!

These topics build on arrays/strings and introduce new data structures.

## Topics

### 1. Linked Lists (Weeks 4-5)
- Singly and doubly linked lists
- Pointer manipulation
- Fast/slow pointer technique
- **Important**: LRU Cache (LC 146) - common interview question

### 2. Stacks (Week 6)
- LIFO principle
- Use cases: parsing, undo operations, monotonic stack
- Implement from scratch

### 3. Queues (Week 6)
- FIFO principle
- Circular queue, deque
- BFS foundation

### 4. Hash Tables (Week 7)
- Hash functions and collision handling
- When to use over arrays
- Time/space trade-offs

### 5. Recursion (Week 8)
- Base cases and recursive cases
- Call stack visualization
- Foundation for trees, graphs, DP

### 6. Sorting Algorithms (Week 8)
- Merge sort, quick sort
- Time complexity analysis
- When to use which algorithm

## How to Approach

1. **Theory first**: Understand the "why" before the "how"
2. **Implement from scratch**: Don't use built-in data structures yet
3. **Solve problems**: Pattern recognition through practice
4. **Compare approaches**: Multiple solutions for same problem

✅ Completed all beginner topics

✅ Comfortable with arrays and strings
✅ Understand time/space complexity

**If yes → Start with Linked Lists!**
**If no → Review beginner topics.**
